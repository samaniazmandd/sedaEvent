# SedaEvent

This project is a full-stack web app made for a school assignment(Web Advanced). It was built as a practical exercise to combine frontend and backend development into one working application.

## What the app does

SedaEvent is an event booking application where users can:

- view available events
- sign up or log in
- reserve tickets for events
- manage their cart and bookings
- explore the app as a user or admin

The project includes both the client-side app and the server-side API, so it behaves like a real web application rather than a static website.

## Tech used

- Frontend: Svelte
- Backend: Node.js + Express
- Database: Sequelize with a relational database
- API documentation: Swagger
- Testing: Vitest

## Project structure

- `client/` contains the frontend interface
- `server/` contains the backend, routes, controllers, and tests
- `documentation/` contains project documentation
- `assignment/` contains the school assignment brief and requirements

## School project note

This app was created as part of a school course, and it was graded with a 7.

## How it was built

The goal of the project was to learn how to build a complete web application from scratch, including:

- designing a user flow
- creating an API
- connecting a frontend to backend data
- handling authentication and user actions
- testing the application logic

## Summary

SedaEvent is a simple but complete event booking app that demonstrates full-stack development skills in a school setting. It shows how a user-facing application can connect to a backend service and provide a working experience for browsing and reserving events.
